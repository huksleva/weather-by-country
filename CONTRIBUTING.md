# Участие в проекте

Изменения приветствуются: исправления ошибок, улучшения документации и тестов.
Проект остаётся небольшим консольным решением на стандартной библиотеке Python.

## Сообщить об ошибке

Создайте [issue](https://github.com/huksleva/weather-by-country/issues/new/choose)
и укажите версию Python, операционную систему, команду запуска,
ожидаемый результат и фактический вывод. Приложите минимальный список городов,
на котором воспроизводится ошибка. Удалите из вывода личные пути и другие
данные, которые не хотите публиковать.

Уязвимости сообщайте приватно согласно [SECURITY.md](SECURITY.md).

## Подготовить pull request

1. Сделайте fork репозитория и создайте отдельную ветку.
2. Внесите изменение, ограниченное одной задачей.
3. При изменении поведения добавьте тест, проверяющий наблюдаемый результат.
4. Если изменились команды или вывод, обновите README.
5. Запустите проверки и создайте pull request с описанием результата.

```console
python -m unittest discover -s tests -v
python main.py --help
git diff --check
```

## Правила разработки

- Поддерживайте Python 3.10 и новее, Windows и Linux.
- Используйте стандартную библиотеку; внешние пакеты не нужны.
- Подменяйте HTTP-ответы в тестах через `unittest.mock`: тесты должны работать офлайн.
- Не подставляйте фиктивные температуры при ошибках API.
- Сохраняйте разделение результатов (`stdout`) и диагностики (`stderr`).
- Для демонстраций используйте настоящий вывод программы и указывайте дату записи.

GitHub Actions автоматически проверит pull request. Проект использует
[MIT License](LICENSE); предлагаемые изменения должны быть совместимы с ней.
